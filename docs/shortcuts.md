## On the canvas

These are fixed and cannot be changed.

| Keys | Effect |
|---|---|
| Space and drag, or middle button | Pan |
| Wheel, Shift and wheel | Scroll, scroll sideways |
| Ctrl or Alt and wheel | Zoom around the pointer |
| Ctrl and drag | Move the layer under the pointer with any tool |
| Arrow keys, with Shift | Nudge the layer or the selection by one pixel, or ten |
| 1 to 9, 0 | Opacity 10 to 90 percent, 100 percent, for brushes, the gradient or the layer |
| [ and ] | Brush size down and up |
| { and } | Brush hardness down and up by 25 percent |
| Escape | Cancel a drag, a polygon or the crop |
| Enter | Close a polygon or apply the crop |
| Ctrl+Enter, Escape | Finish or cancel text while typing |

The modifier keys each tool uses while dragging are listed with the tool in [Tools](tools.md), and the status bar shows them as a hint.

## Changing shortcuts

Help > Keyboard Shortcuts (F1), or Edit > Keyboard Shortcuts, lists every command in two groups, Menus and Tools and Canvas, with a search box. Click a shortcut, then press the new key combination; Escape stops recording and Backspace clears the shortcut. A key given to two commands is reported and Save stays disabled until it is resolved. Restore Defaults puts everything back. Changed shortcuts are kept between launches. The brush size and hardness keys, the opacity digits, Space to pan and the mouse gestures are fixed.
